# PYTHON-MICROPROJECT-
**Introduction:**

The Library Management System program is a simple Python-based application designed to manage the availability of books in a library. It helps in performing basic operations such as issuing books, returning books, and checking the availability of books. This system uses variables to store the number of books available in different categories such as PP, ACDE, AP, and PY, with each category initially containing 25 books (total = 100 books). The program runs continuously using a loop until the user chooses to exit.

**What the Program is Doing:**

This program performs the following main functions:

_Continuous Operation:_ The program runs inside a while True loop, meaning it keeps asking the user for actions until "exit" is entered.

_Issuing Books:_ The user selects a book category (PP / ACDE / AP / PY). Enters the number of books to issue. The program: Checks if enough books are available. If yes → subtracts the issued books. If no → displays “Not enough books”. 3._ Returning Books:_ The user selects a book category. Enters the number of books to return.

_Checking Availability:_ Displays: Number of books in each category Total number of books available

_Exit Option: When the user enters "exit", the program stops execution.

**Conclusion:**

This Library Management System is a basic and interactive program that demonstrates how Python can be used to manage real-world systems like a library. It uses concepts such as loops, conditional statements, and user input handling.

While the program successfully handles issuing and checking availability, it has a minor flaw in the returning section where the book count is not updated properly. With small improvements, this system can become more accurate and efficient.

Overall, it is a good beginner-level project for understanding programming logic and building simple management systems.
